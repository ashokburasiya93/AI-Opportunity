## What's in each deck

1. **Title**: the company and a one-line thesis.
2. **Understanding of Business**: five questions (what it does and who pays, how it makes money, what it must get right, where things go wrong, what data it collects) plus a revenue chart from the latest results.
3. **AI features suggested**: three features, each with the problem it solves, type of AI, data needed, what it improves and the metrics it will impact.
4. **Which feature to build first**: Reach × Impact × Confidence ÷ Effort scoring and a build order.
5. **MVP blueprint**: how the first feature works, MVP scope, success metrics, risks and a rollout plan.

Figures come from Q3 2026 results (for Apple, the June quarter of 2026). Sources are listed in each deck's speaker notes.
Scores and MVP targets are judgement calls and hypotheses to test, not company data.
